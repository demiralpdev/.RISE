01 · JPEG APP11 / JUMBF HARDWARE ATTESTED

Sealed Still Photographs (.rise)

Embeds a signed C2PA-compatible JUMBF manifest directly inside JPEG APP11 segments at shutter release, binding raw sensor light to device silicon.

$ rise-core sign capture.jpg --key enclave.key --out IST_4082.rise
02 · MP4 UUID 72697365 60 FPS MERKLE CHAIN

Continuous Motion Streams (.rvid)

Chains every GOP keyframe into a rolling cryptographic accumulator inside a native MP4 uuid box so spliced or dropped frames are caught immediately.

$ rise-core sign sequence.mp4 --key strongbox.key --out ALP_4104.rvid
03 · 2×2 SPATIAL MERKLE TREE 4 / 4 TILES VERIFIED ✓

4-Tile Spatial Tamper Localization

Partitions every frame into four SHA-256 spatial quadrants (T0–T3) under a single Merkle root, pinpointing the exact region if a pixel is altered.

$ rise-core verify ARC_4089.rise --inspect-tiles // T0..T3 intact
04 · NIST FIPS 204 ES256 + ML-DSA-65

Post-Quantum Dual Cryptographic Seal

Combines classical hardware ECDSA (P-256) with NIST FIPS 204 lattice signatures (ML-DSA-65), keeping archival media verifiable for decades.

$ rise-core keygen --pq ml-dsa-65 --tsa https://freetsa.org/tsr

Install & quickstart.

Copy-paste terminal commands per OS, each ending with a one-line verification step.

macOS (aarch64-apple-darwin) 
curl -fLo rise-core https://github.com/demiralpdev/.RISE/releases/download/v0.2.5/rel-rise-core-aarch64-apple-darwin
chmod +x rise-core && (./rise-core --version 2>/dev/null || ./rise-core --help)
./rise-core keygen --out dev && ./rise-core sign frame.jpg --key dev.key --out frame.manifest.json
./rise-core verify frame.manifest.json frame.jpg --pubkey dev.pub
Linux (x86_64-unknown-linux-musl) 
curl -fLo rise-core https://github.com/demiralpdev/.RISE/releases/download/v0.2.5/rel-rise-core-x86_64-unknown-linux-musl
chmod +x rise-core && (./rise-core --version 2>/dev/null || ./rise-core --help)
./rise-core keygen --out dev && ./rise-core sign frame.jpg --key dev.key --out frame.manifest.json
./rise-core verify frame.manifest.json frame.jpg --pubkey dev.pub
Windows PowerShell (x86_64) 
curl.exe -fLo rise-core.exe https://github.com/demiralpdev/.RISE/releases/download/v0.2.5/rel-rise-core-x86_64-pc-windows-gnu.exe
.\rise-core.exe --version 2>$null; if ($LASTEXITCODE -ne 0) { .\rise-core.exe --help }
.\rise-core.exe keygen --out dev; .\rise-core.exe sign frame.jpg --key dev.key --out frame.manifest.json
.\rise-core.exe verify frame.manifest.json frame.jpg --pubkey dev.pub
npm (@univerisr-ai/rise-cli) 
npm i -g https://registry.npmjs.org/@univerisr-ai/rise-cli/-/rise-cli-0.2.1.tgz
rise --version || rise --help
rise verify frame.manifest.json frame.jpg --pubkey dev.pub
Android ARM64 (Camera2 + StrongBox) 
git clone https://github.com/demiralpdev/.RISE.git && cd .RISE/bindings/android/app
./build_app.sh && adb install -r build/rise.apk
adb logcat -d | grep -i "RISE"
